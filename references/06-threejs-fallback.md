# 06 Three.js 网页白模（用户拒绝安装 Blender 时的降级方案）

目标：用户不装 Blender，也要能**看到镜头怎么走**，并拿到可写进提示词的运动参数。

路线归属：本方案同样走 `SKILL.md` 的六阶段流程——先出 webm 给用户看（阶段 ③），按 `00-flow-intake-iteration.md` 的大白话翻译表迭代（阶段 ④），定稿后导出 JSON 写词（阶段 ⑤），webm 作为运动参考交给视频模型（阶段 ⑥）。只是渲染手段换成网页实时录制，流程与校验口径不变。

## 触发条件

`check_blender.py` 返回 found=false，且用户明确选择"不安装"。仅此一种。其余情况一律优先 Blender。

## 用法（零安装、零构建）

1. 用浏览器打开 `scripts/threejs_previs.html`（单文件，CDN 引入 three，不需要 Node、不需要 npm）。
2. 调参：环绕圆心、起止极角、起止半径、起止机位高、注视高、时长、帧率、分层失重起飞时刻与升幅。
3. 播放：可切换**透视图**（看最终画面）与**顶视图**（看轨迹是否单向、是否折返）。
4. 导出：`导出 JSON` 得到与 Blender 版同结构的逐帧数据；`录制` 得到 webm 参考视频。

## 与 Blender 分支的差异（必须向用户说明）

| 项 | Blender | Three.js |
|---|---|---|
| 坐标精度 | 逐帧世界坐标，可直接引用 | 同公式计算，误差在主观点位与遮挡判断 |
| 穿模检测 | AABB + 射线，逐帧两两校验 | 仅目视，无自动校验 |
| 出片质量 | EEVEE 白模，可加轮廓 | 实时渲染，无阴影细节 |
| 依赖 | 需安装（约 380MB） | 仅需浏览器 + 联网拉 CDN |

## 交付到提示词的方式

网页 `导出 JSON` 的 `cam / rad / ang / pitch` 与 Blender 版字段一致，可直接套 `references/04-prompt-format.md` 的六栏目写法。
但**必须**在交付说明里写一句：本预演为网页实时白模，无穿模自动校验，出片前请重点复核起飞先后与间隙。

## 已知限制与对策

- 离线打不开：CDN 拉不到 three 时页面空白。对策：联网环境使用；或让用户装 Blender。
- 长时间录制不稳定：浏览器 MediaRecorder 受内存限制，超过 15 秒建议分段录制。
- 画幅与镜头畸变不真实：网页不加广角畸变，提示词里的"20mm 超广角边缘拉伸"仍需按参考图描述，不要照网页画面写。
