# 04 一镜到底提示词格式与写作技巧

面向 Seedance / 即梦等视频模型。目标：让模型在**一次生成**里既能对上画面，又能对上运动。

## 六栏目骨架（固定，缺一不可）

```text
【Seedance 2.5 一键版 · N秒】

【Generation Unit】总时长｜画幅｜帧率｜质感与影调｜镜头语言｜节奏三段式

【参考】
@图片1 负责什么（唯一主参考）；是否使用运动参考
空间事实锁定：逐项写死房间与家具
人物锁定：服装、姿态、朝向
摄影锁定：焦段感、光源、焦点策略

【连续性】
不变项（造型、设备数量、屏幕状态）
失重逻辑与因果（谁先飞、谁后飞、为何不穿模）
单向动势声明（唯一方向 + 禁止折返）
画风规则

【旁白和声音】
声轨分层：无旁白/有无环境声/音乐层级

【时间轴·带坐标】
坐标系声明（单位、z 轴、原点）
[段1] 相机起止机位 + 注视点 + 仰角 + 半径 → 画面内容 → 事件时序
[段2] ……
[段n] 收束

【反向提示词】
避免：……
```

## 各栏目写法要点

### Generation Unit
一句话交代"这是什么片子"。必写：总时长、画幅、帧率、质感（写实摄影/胶片颗粒/超广角畸变）、镜头语言（一镜到底/允许隐切）、**节奏三段式**（几秒到几秒做什么）。节奏写出来，模型就不会把动作平铺。

### 参考
- 明确"@图片1 是唯一主参考"，并写清它负责什么、不负责什么。
- **必须写一句"白模/预演仅用于锁定运动，不作为画面参考"**，否则模型会照白模的灰模质感出片。
- "空间事实锁定"用**从左到右/从前到后**的空间顺序罗列物体，比形容词有效。
- "人物锁定"把朝向写死（背向/侧背向镜头、不回头），能显著降低人脸崩坏概率。
- "摄影锁定"用焦段感（20mm 超广角的边缘畸变）+ 光源方向 + 焦点策略，替代"高清、电影感"这类空词。

### 连续性
这一栏目是"防崩坏"的主战场。写法：**因果句**，不要罗列形容词。

- 反例：「桌椅人物一起悬浮，非常丝滑，不会穿模」。
- 正例：「桌面设备先在桌面上方升起约 1.3 米悬停，桌体 5.5 秒后才整体离地，因此上升路径上已无设备，全程无穿模」。
- 必须显式声明"房间墙体、窗、地板保持不动，只有人+桌椅+设备这一组离地"，否则模型会让整个房间一起飘。
- 必须显式声明运镜方向与幅度（如"俯视逆时针单向左环绕约 114°"），并加"绝不反向折返"。

### 旁白和声音
按层写：人声层（无旁白/口播）→ 环境层（键盘、风、摩擦）→ 音乐层（有无节拍、是否封音）。事件点的声音（如离地后的低频气流）要绑时间码。

### 时间轴·带坐标
- 开头声明坐标系：「单位米、z 轴向上、原点在房间地面、房间尺寸、桌面高、人物头顶高、环绕圆心」，让模型知道数字的量级。
- 每段固定四件套：**相机起止机位 → 注视点 → 仰角 → 半径/极角**，再接画面描述与事件时序。
- 坐标必须来自实测 JSON。手填估算值是这一栏最常见的失效原因。
- 描述里加"焦点在哪、前景是谁、谁在虚化"，模型才会分层。

### 反向提示词
按风险分类写，比堆词有效：人物（转身/回头/五官崩坏/多余手指）→ 设备（增减/朝向/屏幕跳变/掉落）→ 几何（穿模/瞬移/错位/椅子穿过人腿）→ 环境（墙体地板漂移/开裂）→ 镜头（折返/抖动/硬切/黑场/闪白）→ 风格（动画化/卡通化/3D 渲染感/过曝/HDR 塑料感）→ 文字（字幕/水印/logo/UI 特写）。

## 十条高频失效原因与对策

| 现象 | 对策 |
|---|---|
| 人物转头露脸、五官崩 | 【参考】写死"全程背向镜头不回头"；【反向】前置"转身、回头、人脸特写" |
| 动作平铺无节奏 | 【Generation Unit】写三段式节奏与秒点 |
| 房间跟着飘 | 【连续性】声明只有一组物体离地、墙地不动 |
| 设备穿模、桌椅穿腿 | 【连续性】写起飞先后因果，不用"注意不要穿模"这类否定句 |
| 镜头方向鬼畜 | 【连续性】声明唯一方向与角度幅度；时间轴各段动势必须承接 |
| 画面像灰模/3D 渲染 | 【参考】声明白模不作画面参考；【反向】加"3D 渲染感、塑料感" |
| 主体出画 | 时间轴每段写清机位与注视点，镜头高度跟随主体 |
| 生成画面太空/没层次 | 时间轴每段写前景、中景、远景各是什么 |
| 屏幕内容乱跳 | 【连续性】写"屏幕保持亮着并维持原界面"；【反向】加"屏幕内容跳变" |
| 收尾仓促 | 明确"最后 0.4–0.6 秒减速到近乎静止，不黑场不淡出" |

## 时长裁剪

- 平台只给 5 秒：保留「起手 + 轻物起飞」，砍掉人物离地段，收尾改为"设备悬停、镜头继续环绕、画面静止"。
- 平台给 10 秒：完整走完「起手 → 分层起飞 → 主体离地 → 仰视收束」。
- 超过 12 秒：建议在遮挡处做隐切（贴物件全遮挡瞬间切），或拆成两条素材。

## 交付格式

- 提示词正文放进 ```text 代码块，用户可整段复制。
- 正文之后附：实测数据表（相机轨迹 + 失重时序）、校验结论（穿模对数/出画帧数/仰角范围）、使用说明（标签核对、坐标平移、裁剪方案）。
