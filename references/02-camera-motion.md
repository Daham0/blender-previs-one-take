# 02 运镜设计规范

## 参数化优先于手动 K 帧

一镜到底最容易出的问题是"方向鬼畜"。根源是用手拖关键帧，曲线在关键帧之间回弹。正确做法是把相机轨迹参数化成四个变量，逐帧求值：

- `rad(t)` 环绕半径（水平距离），前推即递减，后拉即递增
- `ang(t)` 极角（俯视图里相对圆心的方位角），**必须单调**
- `camz(t)` 机位高度
- `lookz(t)` 注视点高度（决定仰俯角）

相机位置：

```
cam = (cx + rad*cos(ang), cy + rad*sin(ang), camz)
look_at = (cx, cy, lookz)          # 圆心正上方，或给焦点加小偏移
pitch = atan2(lookz - camz, rad)   # 正值=仰视，负值=俯视
```

关键：`ang` 用线性或缓入缓出曲线，**不做回弹**；其余三个变量各自单调，就能保证"丝滑、单向、不抖"。

## 极角方向与画面观感

极角递增/递减只决定"顺时针还是逆时针"，真正决定画面观感的是**相机相对人物的方位**。开工前先确定三件事：

1. 主体朝向哪边（人物面朝哪、产品正面朝哪）。
2. 镜头从主体的哪个方位进（背后 / 左后 / 右后 / 正面 / 侧面）。
3. 镜头最终收在哪个方位。

只要这三件事定了，运镜就不会"绕到不该绕的位置"。例如人物在办公，镜头全程留在人物后方（左后 → 右后），人物始终背对镜头，既避免正脸崩坏，又能同时读到双屏与人物关系。

## 三条硬规则

1. **单向连续**：`ang` 一阶差分符号全程不变。俯视图轨迹要画出来目视确认，出现"折返钩"立即改曲线。
2. **跟随升空**：主体升空时，`camz` 与 `lookz` 必须同步上移，跟随系数 0.8–0.95（略慢于主体上升，保留"被追上升"的观感）。不跟随则主体 2 秒内出画。
3. **仰俯角有意图**：轻微仰视（3°–10°）最能强化"悬浮/巨大化"；俯视适合交代空间关系；仰视角在片内应有变化（例如 6° → 3.7° → 7.9°），但不得跨越 0° 反复翻越。

## 起手与收束

- **起手**用极近前景（机箱侧板、桌沿、门框）贴画面边缘划过，制造速度与纵深；前景物件应虚化。
- **收束**最后 0.4–0.6 秒减速到近乎静止，构图稳定可读，不黑场、不淡出、不加转场。
- 速度曲线：起手匀速偏快 → 中段放缓 → 收束接近静止。中段是最容易"看起来在漂"的地方，要靠前后景的相对位移维持速度感。

## 校验方法

- 极角：`np.diff(ang)` 全为正或全为负
- 出画：`bpy_extras.object_utils.world_to_camera_view` 逐帧算主体各关键点的 NDC，x、y 必须落在 [0.02, 0.98]
- 天花板：所有物体最高点 + 安全余量 ≤ 层高
