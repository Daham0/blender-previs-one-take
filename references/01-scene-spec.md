# 01 场景搭建与坐标标定规范

## 为什么先建场景

写提示词时若没有真实坐标，只能凭想象填机位，结果就是：物体尺寸比例失真、镜头贴太近导致穿模、升空高度超过层高、环绕半径与画面景别不匹配。先建场景，一切坐标从场景里量出来，提示词才有可复现性。

## 标定规则

1. **1 单位 = 1 米**。Blender 默认单位即米，建场景前确认 `scene.unit_settings.scale_length = 1.0`。
2. **原点落在地面**，通常取房间几何中心在地面的投影。所有物体 z 值 = 离地高度，直接可读。
3. **z 轴向上**，导出给提示词时说明"z 轴向上、原点在房间地面"，方便跨工具对齐。
4. 建立**坐标清单表**（物体名 / 中心 xyz / 尺寸），落盘为 `coords.md` 或 `coords.csv`。
5. 输出三张核验图：同机位对照图（白模 vs 参考图同角度）、正交俯视图、正交正视图。三张图都能读出尺度比例才算通过。

## 白模构件的最小集合

| 构件 | 要求 | 说明 |
|---|---|---|
| 房间 | 长×宽×高，墙体厚可忽略 | 高度决定升空上限（升空后物体顶部不得超层高） |
| 地面 | 单独平面，便于投影 | 悬浮感全靠地面与物体距离可读 |
| 家具 | 按参考图位置与尺寸摆放 | 桌面高度、椅坐面高度是关键参照 |
| 人物 | 块面近似即可（头球+躯干+四肢+鞋） | 需要单列头、躯干、鞋，方便校验 NDC |
| 屏幕/设备 | 屏幕中心点单列 | 用于"设备与桌面高度差"校验 |
| 光源 | 一盏面光 + 世界环境光即可 | 白模不看质感，只要能看清轮廓 |

## 本次已验证的场景参数（悬浮办公，可直接复用为模板）

- 房间 6.80 × 6.40 × 2.75 m，原点在地面中心 (-0.40, 0.20, 0.00)
- 桌面高 0.75 m；横屏屏幕中心 1.14 m；竖屏屏幕中心 1.16 m
- 椅坐面 0.50 m（静止）；人物头顶含帽 1.355 m（坐姿 1.24 m）
- 场景物体总数 131，含置物架小摆件、黑胶唱片机、风扇、三脚架等

## 摆位原则

- 前景 / 中景 / 远景三层必须有物件（近处桌沿与机箱、中景人物与双屏、远景置物架与墙），否则镜头一动画面就"空"。
- 不要默认对称构图，除非用户明确要求。默认用偏轴构图，给环绕留出运动余量。
- 环绕镜头的圆心应落在**主体**（人物或产品）上，而不是房间中心；这样环绕时主体始终居中、背景自然流动。
